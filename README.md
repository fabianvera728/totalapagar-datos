# Datos y código de Total a Pagar

[Total a Pagar](https://www.youtube.com/@totalapagar) es un canal de YouTube que hace la cuenta de lo que de verdad cuesta lo que la gente quiere y muestra quién se queda con ese dinero. Este repositorio guarda los datos y el código de cada cuenta, para que puedas revisarla, rehacerla o usarla.

La explicación completa de cada cuenta, con las fuentes y la transcripción, está en [totalapagar.com](https://totalapagar.com).
